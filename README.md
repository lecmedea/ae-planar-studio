# AE Planar Studio

Install this directory as `ae-planar-studio` under the Codex skills directory or the DeepSeek Harness filesystem skill root (`~/.dsh/skills` by default). Start a fresh session and request the skill by name. Both editions use the same instructions. The host needs access to After Effects and the Mocha window to perform a native solve.
